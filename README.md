# Cryptocurrency Market Trends Dashboard

Fetches live market data from the CoinGecko public API and visualizes the top 20
coins by market cap, with a click-through 7-day price chart rendered in Chart.js.
Vanilla JavaScript, no build step, no API key required.

## Run locally

```bash
python3 -m http.server 8000
```

Then open `http://localhost:8000`.
